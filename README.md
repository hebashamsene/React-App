# React Loan Form

A simple loan application form built with **React.js**.

## 📌 About the Project

This project is a React application that provides a user-friendly loan application form.

The application demonstrates how to manage form data and user interactions using React Hooks, especially `useState`, and how to display a modal component based on the application state.

## 🚀 Features

* Loan application form
* Form input handling
* State management using `useState`
* User interaction handling
* Conditional rendering
* Modal component
* CSS styling
* Simple and responsive user interface

## 🛠️ Technologies Used

* React.js
* JavaScript
* React Hooks (`useState`)
* CSS
* HTML

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/hebashamsene/React-App.git
```

Go to the project folder:

```bash
cd React-App
```

Install the dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```
